# Problem CF - непрерывные дроби

Вам на вход приходят числитель и знаменатель дроби.

Ваша задача: написать программу выдающую на стандартный вывод представление цепной дробью.

## Пример 1
| Ввод | Вывод |
| -----|------ |
| 1 3  | 0 3   |

## Пример 2
| Ввод  | Вывод   |
| ------|-------- |
| 43 19 | 2 3 1 4 |

## Пример 3
| Ввод    | Вывод        |
| --------|------------- |
| 345 678 | 0 1 1 27 1 3 |
