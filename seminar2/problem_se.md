# Problem SE - количество простых чисел

На стандартном вводе дано число n.

Вам надо вывести на стандартный вывод количество простых чисел меньших или равных n.

## Пример 1
| Ввод | Вывод |
| -----|------ |
| 13   | 6     |

## Пример 2
| Ввод    | Вывод   |
| --------|-------- |
| 1000000 | 78498   |

## Пример 3
| Ввод    | Вывод |
| --------|------ |
| 1000    | 168   |
